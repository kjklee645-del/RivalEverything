# Rival Everything MVP 플레이테스트 체크리스트

## 1. 테스트 목적

이 테스트는 `Rival Everything` 웹 MVP가 5~15분 안에 끝까지 플레이 가능한지, 그리고 핵심 루프가 플레이어에게 이해되고 기억되는지 확인하기 위한 소규모 플레이테스트다.

확인할 핵심 질문은 다음과 같다.

- 플레이어가 대칭자를 "단순한 적"이 아니라 "내가 선택하지 않은 가능성"으로 이해하는가?
- 선택 결과와 대칭자의 흔적이 플레이어의 선택을 다시 생각하게 만드는가?
- 최소 1개의 선택이나 결과가 플레이 후에도 기억에 남는가?
- 텍스트량과 UI 흐름이 5~15분 세션 안에서 피로하지 않은가?
- 다른 정체성이나 다른 선택으로 다시 플레이해보고 싶은 마음이 생기는가?

## 2. 테스트 전 안내 문구

테스트 진행자는 플레이어에게 아래 문구만 읽어준다. 게임의 의도나 정답을 설명하지 않는다.

> 이 게임은 작은 섬에서 정체성을 고르고, 몇 가지 선택을 한 뒤, 그 결과를 확인하는 짧은 웹 MVP입니다. 정답을 찾는 테스트가 아니며, 어떤 선택을 해도 괜찮습니다. 플레이 중 막히거나 헷갈리는 지점이 있으면 평소처럼 행동해 주세요. 테스트가 끝난 뒤 어떤 점을 이해했는지, 어떤 점이 기억에 남았는지 질문드리겠습니다.

사전 조건:

- 플레이 시간 목표: 5~15분
- 관찰자는 플레이 중 개입하지 않는다.
- 플레이어가 명확히 도움을 요청할 때만 조작 방법을 짧게 안내한다.
- 플레이 중 떠오른 말은 가능하면 소리 내어 말해달라고 요청할 수 있다.

## 4. 플레이 후 질문

질문은 아래 순서대로 묻되, 플레이어 답변을 바로잡거나 유도하지 않는다.

1. 방금 플레이한 내용을 짧게 설명한다면 어떻게 말하겠나요?
2. 가장 기억나는 장면이나 선택은 무엇이었나요?
3. 이해하기 어려웠던 순간이 있었나요?
4. 선택 결과를 확인한 뒤 생각이 바뀐 순간이 있었나요?
5. 끝까지 플레이하는 동안 길을 잃거나 멈춘 순간이 있었나요?

## 5. 대칭자 이해도 질문

목표: 플레이어가 대칭자를 어떻게 해석했는지 확인한다.

1. 대칭자는 어떤 존재라고 느꼈나요?
2. 대칭자가 한 일 중 기억나는 것이 있나요?
3. 대칭자의 선택은 플레이어의 선택과 어떤 관계가 있다고 보였나요?
4. 대칭자가 남긴 흔적은 게임을 이해하는 데 도움이 되었나요?
5. 대칭자가 적, 조력자, 또 다른 가능성, 또는 다른 무언가 중 무엇에 가까웠나요? 그렇게 느낀 이유는 무엇인가요?

판정 메모:

- `명확`: 대칭자를 "내가 선택하지 않은 가치/가능성"에 가깝게 설명한다.
- `부분`: 반대 선택을 하는 존재로 이해하지만 의미를 충분히 설명하지는 못한다.
- `불명확`: 적, 방해자, 임의 이벤트로만 이해한다.

## 6. 선택 몰입도 질문

목표: 딜레마가 정답 맞히기가 아니라 가치 충돌로 읽혔는지 확인한다.

1. 선택할 때 무엇을 기준으로 골랐나요?
2. 선택지 중 어느 쪽이 더 쉬웠거나 어려웠나요?
3. 어떤 선택에서 가장 오래 고민했나요?
4. 선택 후 결과가 예상과 달랐던 순간이 있었나요?
5. 선택이 세계나 사람들에게 영향을 줬다고 느낀 순간이 있었나요?

## 7. 텍스트 피로도 질문

목표: 모바일/짧은 세션 기준으로 읽기 부담이 적절한지 확인한다.

1. 읽어야 하는 글의 양은 어땠나요?
2. 너무 길다고 느낀 화면이나 문장이 있었나요?
3. 더 읽고 싶었던 정보가 있었나요?
4. 선택지 설명과 결과 문장 중 어느 쪽이 더 부담스러웠나요?
5. 플레이 흐름을 끊는 텍스트가 있었다면 어디였나요?

피로도 기록:

| 구분 | 선택 |
| --- | --- |
| 전체 텍스트량 | 적음 / 적절함 / 많음 |
| 선택지 길이 | 짧음 / 적절함 / 김 |
| 결과 문장 길이 | 짧음 / 적절함 / 김 |
| 대칭자 로그 길이 | 짧음 / 적절함 / 김 |

## 9. 다시 플레이 의향 질문

목표: 다른 정체성이나 다른 선택으로 재플레이할 동기가 생기는지 확인한다.

1. 다시 플레이한다면 어떤 선택을 다르게 해보고 싶나요?
2. 다른 정체성을 골라보고 싶은 마음이 있었나요?
3. 다시 플레이하고 싶지 않다면 가장 큰 이유는 무엇인가요?
4. 한 번 더 플레이한다면 확인하고 싶은 결과가 있나요?
5. 이 MVP가 짧은 플레이 경험으로 충분히 완결되어 보였나요?
