# Rival Everything Prototype

모바일 앱으로 발전시키기 전, 핵심 루프를 검증하는 정적 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열거나, 로컬 서버로 실행합니다.

```sh
python3 -m http.server 5173
```

## 테스트

```sh
node tests/core.test.js
```

## 핵심 루프

- 3개 윤리 축으로 플레이어 정체성을 선택합니다.
- 대칭자는 반대 윤리 축으로 자동 생성됩니다.
- 작은 섬의 3개 딜레마를 해결하면, 대칭자는 마일스톤마다 다른 장소에 반대 선택의 흔적을 남깁니다.
- 세 딜레마를 모두 해결하면 대칭자의 흔적 하나를 통합해 엔딩을 봅니다.
